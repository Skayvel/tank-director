## 读之前请接受三件事

1. **静态证据不等于运行时行为。** 本目录几乎所有结论都停在「编译/指令层 + 待实测」。
2. **未知不等于不存在。** 报告写「未找到生产者」，意思是「在声明的证据集合里没找到」。
3. **改一个字段不等于改一个行为。** 字段写入、vtable 绑定、局部 CFG 都不是行为证明。
