# 公开发行范围

本仓库是**公开发行版**，与内部研究工作区（下称"研究仓库"）是两个独立的目录树。本文说明：收录了什么、排除了什么、为什么。

判定原则：**只公开我们自己写的、可独立验证的、分发后不产生权利风险的内容。**

---

## 1. 收录

| 类别 | 路径 | 说明 |
|---|---|---|
| 插件源码 | `scripting/` | 自行编写的 SourcePawn 代码，7 个可编译目标 |
| 原生签名 | `gamedata/tankrun_firstrock.txt` | 40 字节指令模式，不含游戏代码 |
| 配置样例 | `configs/` | 4 份服务器配置，无私有路径 |
| 构建工具 | `tools/` | 编译、打包、链接检查 |
| 发布包 | `dist/` | v2.2.8 成品 + `SHA256SUMS.txt` |
| 技术文档 | `docs/` | 安装、使用、接口、研究结论摘要、构建、测试 |
| 第三方说明 | `third_party/` | 依赖清单与版权/许可矩阵，不含第三方代码 |
| 许可证与声明 | `LICENSE`、`NOTICE` | GPLv3 全文；三方归属、编译期嵌入说明、gamedata 披露 |

## 2. 排除

| 排除内容 | 原位置 | 理由 |
|---|---|---|
| 反编译转储（`.c` / `.asm`） | `analysis/decompiled/`、`analysis/**/code/`、`evidence/**` | **游戏二进制的衍生物**。权利状态未明，不宜公开分发 |
| REA / Ghidra 导出 | `evidence/rea/`、`evidence/exports/`、`evidence/dossiers/` | 同上；含分析数据库的原始响应 |
| 第三方源码副本 | `evidence/parameter-control/sources/` | 来自第三方仓库的镜像，未经许可不转发 |
| 原生研究报告全文 | `analysis/**/*.md` | 依赖上述转储才能复核；脱离证据的结论无法验证，公开反而不可信 |
| 机器可读索引 | `indexes/` | 与上述语料配套，离开语料无意义 |
| 历史构建与备份 | `build/`（2.67 GB） | 体积大、多为过期产物；只保留当前发布包 |
| 内部派工与验收记录 | `docs/coordination/` | 内部协作材料，含对话链接与私有上下文 |
| 本机绝对路径 | 散落在历史文档 | 泄露目录结构；新文档一律使用相对路径 |
| 旧版本文档正文 | `docs/*.md`（平铺 37 份） | 与当前版本冲突（详见下文 §4），保留在研究仓库 |

## 3. 研究内容是如何公开的

研究报告不公开，但**结论仍然公开**，只是换了形式：

| 公开 | 不公开 |
|---|---|
| [已验证结论](../research/verified-findings.md)：哪些命题被指令支持，附地址与证据 ID | 具体的反汇编窗口与伪代码 |
| [实验性结论](../research/experimental-findings.md)：哪些有运行时观测但条件不足 | 原始日志文件（含本机路径） |
| [未解决问题](../research/open-questions.md)：哪些没闭合、下一步从哪进 | 内部 frontier 索引 |
| [研究方法](../research/method.md)：`D`/`I`/`API`/`R`/`U` 与 F0–F7 的定义 | 分析数据库会话记录 |
| [原生接口研究](../research/interfaces/README.md)：ConVar 消费点、Hook 能力边界 | 第三方插件源码镜像 |

**取舍理由**：结论可以独立评估（有地址、有前提、有反例），而证据链需要整个语料才能复核。公开半个语料只会制造"看起来可验证、实际验证不了"的错觉。

如果你需要复核某条结论，公开文档里给出了地址与证据 ID，可以在你自己的游戏构建上重新验证——这正是项目一贯要求的方式。

## 4. 旧版本文档为什么不公开

研究仓库里 `docs/*.md` 有 37 份按轮次累积的工作报告，它们的版本描述与当前产品**不同步**（例如把当前主线写成 v2.0.1、描述已移除的 763→761 动作改选）。

公开它们会制造矛盾。因此：

- **当前事实**以本仓库的 `docs/reference/versions.md` 为准；
- **历史演进**在 [项目历程](history.md) 中按阶段概括；
- **逐版本技术细节**保留在研究仓库，需要时由维护者提供。

## 5. 公开版本做了什么改动

相对研究仓库，公开版对文档做了三类改动：

1. **断链改写**：指向 `analysis/`、`evidence/`、`indexes/`、`build/` 的相对链接，改成代码片段形式并注明"研究仓库"。原文措辞不变。
2. **下载路径**：`build/releases/2.2.8/...zip` → `dist/...zip`。
3. **仓库定位**：根 `README.md` 重写；`docs/README.md` 增加"本仓库没有收录什么"；`docs/player/README.md` 去掉存档链接。

**源码与 `gamedata` 未做任何改动**，与发布包内的二进制一致（见 [公开发布检查报告](../audit/public-release-report.md) 的构建验证）。

## 6. 如果你认为某内容应该公开

请先确认三点：

1. 它是否包含游戏二进制的衍生物（反编译、导出、字节窗口）？
2. 它是否来自第三方且没有明确的分发许可？
3. 它是否包含本机路径、用户名、私有对话链接？

三项任一为"是"，就不适合进公开仓库。其余情况可以提 issue 讨论。
